# Roadmap — Jogo de Memória Visual

## MVP

- [x] Seleção de 1, 3 e 5 minutos
- [x] Geração aleatória do tabuleiro
- [x] Fase de memorização
- [x] Fase de localização
- [x] Feedback de acerto/erro
- [x] Pontuação e resumo da partida

- [ ] Login/perfil
- [ ] Ranking global
- [ ] Multiplayer
